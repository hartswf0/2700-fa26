This proof surface makes one distinction visible: changing a constructor default does not reach backward through time and rewrite already-created instances. A class describes how a new trout begins; an instance carries its own state after construction.

PROGRAM THEORY

<class> [describes] how an entity begins and what operations it can perform.
<instance> [stores] the current state of one particular entity.
new Trout() [copies-from] <constructor defaults> at the moment of creation.
<later class change> [does not automatically rewrite] <existing instance state>.

VISIBLE TESTS

TEST 1. Set class default to 3.0. Existing trout should not suddenly become faster.
TEST 2. Spawn a trout. The new instance should inherit the new 3.0 starting speed.
TEST 3. Select one trout and slow it to 0.2. Only that individual should change.
TEST 4. Apply the selected value to all. Now the population changes because you explicitly iterated over the array.
