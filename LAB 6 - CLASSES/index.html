Wilson’s mismatch, translated into Trouttown

“Paleolithic emotions, medieval institutions and godlike technology.”
PALEOLITHIC EMOTIONS

<inside the instance>

Fear, affiliation, appetite, imitation. In code, these are individual properties and local behaviors.

MEDIEVAL INSTITUTIONS

<rules around the instance>

Tolls, ranks, gates, courts, abbeys. The world changes which actions are permitted or rewarded.

GODLIKE TECHNOLOGY

<amplified signal>

The lure turns attention into force. One click can overpower the slower institutional rules and pull the whole school.

Important: this lab does not claim that human institutions can be reduced to fish instincts. The point is almost the opposite. A simulation forces its assumptions into the open. The funny trout make it easier to ask the serious question: what did the programmer decide an actor was before the program ever ran?

Before code: theory skeleton

  • Name the main <entity>. What makes one instance that kind of thing?
  • Name at least two [operations] it can perform.
  • List the state each instance must carry independently.
  • State one <invariant> that should remain true every frame.
  • Expose one assumption your model makes about behavior.
  • Write one change test: “If I changed ___, what code should survive?”

Trouttown extension

<individual> [enters] <institution>
<condition> [enables-or-blocks] <transition>
<population> [produces] <visible pattern>
  • Invent one institution whose rule changes behavior.
  • Do not create a second species just to fake the rule. Let the environment matter.
  • Make the effect visible enough that a classmate can infer the rule without reading your code.
  • Funny is welcome. Invisible is not.

Core requirements

  • At least one JavaScript class you define.
  • An array or collection containing multiple instances created with new.
  • Methods such as update() and display() that make each instance do something.
  • The sketch must run in p5.js and make the instances visibly independent.

Deliverables

  • One PDF containing the link to your p5.js sketch.
  • A 3–4 sentence description of the interaction and what you wanted users to feel or notice.
  • A screenshot of the working sketch and code.
  • Separate video upload showing the interaction.
LINEAGE. E. O. Wilson’s 2009 formulation is used as a conceptual provocation; Craig Reynolds’s 1987 “Flocks, Herds, and Schools” provides the computational precedent for local rules producing aggregate motion.
