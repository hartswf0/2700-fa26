Tips and Tricks
Start very small: a single rectangle, then gradually add more shapes.
Use comments in your code to label parts of the composition (for example, “big red rectangle”, “thin black line”).
If the canvas is blank, check the browser console for errors; a single typo can prevent setup() from running.
Try picking 3–4 colors and stick to those, rather than using every color.
