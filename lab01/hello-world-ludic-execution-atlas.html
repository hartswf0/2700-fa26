Operational definition

Canvas and grid

400 and 400 are not “just numbers.”

(0,0)
x = horizontal position, rightward
y = vertical position, downward
grid unit = 40 logical units
400 ÷ 40 = 10 columns and 10 rows
Number cards

400

400

Role: canvas height

220

Imposter challenge

        
Which one looks fine but is broken underneath?

      

      

        
        
        
      

      

        
Answer

        
C is broken: the call does not supply the full width/height contract. A is the subtle imposter: it may look correct for a static gray canvas, but the clearing operation lives in the wrong lifecycle if the sketch later animates. B preserves the architecture.

      

    


    

      

        
Good code includes negative space

        
Every operation says what it refuses.

      

      

        

          
createCanvas

          
does:
  creates drawing surface

requires:
  p5 runtime
  width number
  height number

preserves:
  source text

signals:
  missing argument
  missing p5

        

        

          
Does not

          
does not:
  start draw by itself
  set the background color
  create animation
  explain coordinates
  guarantee physical pixel count
